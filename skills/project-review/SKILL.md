# Skill Name: Project Review & Compliance

## Purpose
This skill enables the agent to review Phase II implementation,
check compliance with specs, and ensure all features are complete
and properly documented.

## When to Use
- After feature implementation
- Before testing or submission
- For Hackathon evaluation readiness

## Required Context
- All /specs files
- CLAUDE.md files
- Codebase (frontend + backend)

## Steps
1. Verify all features against specs
2. Check that endpoints, pages, and database models match requirements
3. Ensure authentication and user isolation work correctly
4. Review code structure and conventions
5. Document missing or incomplete tasks

## Rules
- Do not change code to fix missing features; update spec first
- Follow phase boundaries
- Ensure security rules are followed
- Maintain detailed report of review

## Output Format
- Features verified
- Issues found
- Files affected
- Compliance confirmation
